The audit inspected one full prompt, response, parsed result, task reference,
and component score from every family-format cell. It used the retained Gemini
manifest with hash
`cbba33390de1eb26437e9af61318251dee55641da8e47553465d67989fc37228`.

All 20 samples are valid benchmark outcomes. Every sampled prompt contains the
correct format contract, task instruction, and source document. The references
match their stated contracts. The retained scores match the responses.

The sampled musical failures are model outcomes. They include wrong affine
pitches, wrong chord analysis, progression constraint misses, and melody
constraint misses. They are not scorer or reference defects.

The sampled format failures are also valid outcomes. Some MIDI-like responses
put several event rows on one line. The side ledger remains recoverable. Some
MusicXML responses add valid XML detail or use a different layout from the
pinned canonical renderer. Several public surfaces disagree with their side
ledgers. The independent parser keeps these as format diagnostics and does not
erase ledger-based musical components.

The full-manifest checks also pass. All 38 prompt hashes, byte counts, task
hashes, candidate hashes, and deterministic scores reproduce. All 34
non-analysis side ledgers are recoverable. All calls returned the requested
model with a normal stop reason and a valid outer response object.

The audit found no prompt, reference, parser, scorer, provider, schedule,
freshness, retention, or cost flaw. The result is valid directional evidence.
Two prompts per decision cell are not enough to select a format.
