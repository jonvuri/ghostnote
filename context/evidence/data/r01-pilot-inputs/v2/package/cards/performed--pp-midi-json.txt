FORMAT: Producer Pal MIDI JSON

SCOPE
Performed core-note cohort; fixed 4/4, channel 1, clip length 64 quarter notes.

INPUT AND OUTPUT GRAMMAR
Return an array of native object literals. This language is not standard JSON: keys may be unquoted and numeric fraction expressions are accepted. Each note uses p for MIDI pitch, t for onset, d for duration and v for integer velocity. In this fixed 4/4 scope, t and d are quarter-note beats; onset zero is the clip start. Emit all four fields for each note. Optional vd is velocity deviation (default 0); c is probability (default 1). State does not carry across objects, so each object defines its own note. No wrapper, group records, persistent IDs or extra fields belong in this grammar.

PRESERVATION
Channel 1 and clip scope come from the task contract. Preserve the full performed multiset and duplicate multiplicity; object order does not establish identity. The native parser can clamp invalid values, skip malformed notes and treat velocity zero as deletion; these behaviors do not excuse an incorrect result. Use valid pitch 0–127, velocity 1–127 and positive duration, and preserve every unaffected encoded note.

COMPLETE FORMAT EXAMPLE
[{p:62,t:65/512,d:0.75,v:73},{p:69,t:705/512,d:0.5,v:85}]
