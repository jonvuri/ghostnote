# Item — outcome

Use this optional outline when scope, choices, or a handoff needs a brief.
Omit sections that add no useful information. The backlog holds work status.

## Goal

State the useful result and the reason for the change. Link the backlog item
and the sources needed to make the relevant decisions.

## Work and acceptance

Describe the changes and the checks that establish the result. Name unresolved
choices only when they can change the implementation. Distinguish a required
outcome from a proposed mechanism. For live work, identify the target, bounds,
operator actions, and cleanup. Use relevant cost evidence when changing a live
path.

## Result

Record the result, verification, and material limits. Link separate evidence
only when later work needs citation or reproduction. Update the backlog and
handoff facts that changed.
