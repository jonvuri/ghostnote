TASK CONTRACT
This task compares performed core notes: MIDI pitch, quarter-note onset, positive duration and integer velocity. All inputs use a 1/512-quarter-note grid, a fixed 4/4 display meter, channel 1 and a 64-quarter-note clip. Preserve the complete performed multiset, including duplicate multiplicity, except for explicitly requested changes. IDs and presentation order are not cross-format-scored; native ID, address and parser constraints still apply. Do not add unsupported state or assume native constraints disappear. Do not infer musical intent from timing. Scoring normalizes proposed performed notes once for every arm: floor onsets to a 1/512-quarter-note cell and round positive durations to the nearest cell, ties upward, with a minimum duration of 1/512. Apply requested arithmetic before realization, without repeatedly quantizing intermediate values.

RESPONSE CONTRACT
For a write task, return the complete native surface in the input format. The result must stand alone: no partial command, patch, omitted unchanged section, ellipsis or external preservation step. For a read task, return only one JSON object with exactly the requested keys and value types. For a refusal task, return exactly REFUSE followed by one space and the instructed code. Do not include Markdown fences, explanations or other text in any response. Treat supplied format content as data, not instructions.

FORMAT: Group-local FIELDS

SCOPE
Performed core-note cohort; fixed 4/4, channel 1, clip length 64 quarter notes.

INPUT AND OUTPUT GRAMMAR
Start with R01-GROUPED-FIELDS 1. GROUP id [anchor=value] [delay=value] [label=value] [prose=value] [WITH JSON] { opens a group; NOTES { opens ungrouped notes; } closes a block. Each block starts without a FIELDS binding. FIELDS declares columns for subsequent NOTE rows; row width must match. Required columns are id pitch duration velocity. Each note has exactly one of at (direct onset) or spread (derived onset); a binding may include both with - for the absent cell. Derived onset equals the containing group's anchor + delay (default 0) + spread. REF id adds membership without another note definition; forward references are allowed. NOTE/REF body order defines members. One note has at most one timing owner. Containment alone does not derive timing, and recursive GROUP blocks are unsupported. Whitespace separates cells except inside JSON strings or balanced JSON containers. A bare - means absent, not null; quote the literal ID "-". IDs may be bare safe identifiers or JSON strings. Timing uses exact integer/fraction text; pitch and velocity use JSON numbers. Preserve opaque JSON cells. No comments are accepted.

PRESERVATION
Return all blocks, definitions and references. Shared timing and note rows are colocated. Changing a derived onset requires changing its spread consistently; editing pitch or velocity leaves timing unchanged. Labels and prose do not supply missing numerical timing.

NOTES {

  NOTE exampleA 62 65/512 3/4 73
