TASK CONTRACT
This task compares the complete source fixture: exact rational values and spellings, IDs, note/group/member order, nominal timing, annotations, provenance, interpretation state and opaque properties. Preserve everything except explicitly requested changes and the required lifecycle updates. Do not quantize source or nominal timing. Group/member order, note presentation order and explicit performanceOrder are distinct. Nominal timing describes supplied intent and never overrides performed timing.

When a member's pitch, onset or duration changes, mark an inferred group state stale, retaining its label and provenance. Inferred nominal timing becomes stale only on onset/duration changes; mapped nominal entries inherit musical.provenance when their own provenance is absent. Declared intent remains declared; velocity-only edits stale neither interpretation. An onset edit recomputes its owned spread as onset minus anchor minus delay. A spread transform changes only explicit spreads and their onsets, preserving common delay and durations. A stale group or missing decomposition cannot drive that transform. Do not invent or repair interpretations.

INPUT AND OUTPUT GRAMMAR
Start with R01-DETACHED-FIELDS 1. GROUP id [anchor=value] [delay=value] [label=value] [prose=value] [WITH JSON] { contains exactly one ROWS rN reference and then }. A matching top-level ROWS rN { ... } contains that group's FIELDS/NOTE/REF body, with the same meaning as if nested inside the GROUP. The reference may precede the ROWS definition. NOTES blocks remain direct. Each block starts without a FIELDS binding. FIELDS declares columns for subsequent NOTE rows; row width must match. Required columns are id pitch duration velocity. Each note has exactly one of at (direct onset) or spread (derived onset); a binding may include both with - for the absent cell. Derived onset equals the containing group's anchor + delay (default 0) + spread. REF id adds membership without another note definition; forward references are allowed. NOTE/REF body order defines members. One note has at most one timing owner. Containment alone does not derive timing, and recursive GROUP blocks are unsupported. Whitespace separates cells except inside JSON strings or balanced JSON containers. A bare - means absent, not null; quote the literal ID "-". IDs may be bare safe identifiers or JSON strings. Timing uses exact integer/fraction text; pitch and velocity use JSON numbers. Preserve opaque JSON cells. No comments are accepted.
Optional order cells preserve original note-array positions and must form a complete zero-based permutation when used. spelling preserves the exact rational spelling of a derived onset and must equal its equation. nominal is a JSON shared-map entry; extra retains other note fields, including note-local nominal. CONTEXT retains root properties except notes/groups; mapped nominal entries leave an empty musical.nominal marker. EMPTY_GROUPS preserves an explicitly empty group array. Group WITH retains other properties, including provenance, state and explicit orders; it cannot redefine structural fields.

PRESERVATION
This is a layout diagnostic, not the primary grouped candidate. Preserve the one-to-one group/body linkage. Shared timing comes from the linked GROUP; ROWS placement does not create another group or reorder source members. Return every definition and reference.
