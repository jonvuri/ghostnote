# Historical wire probes

Session 8b removed 120 direct npm probe commands and one compound command that
request a historical wire method. Their source files remain in this directory
because they explain the evidence that selected current product rules.

`RuntimeProfile.HISTORICAL` is the exact 57-method boundary. No active extension
profile registers those methods. Do not run an archived source file against a
current extension. Use its owning evidence document or a historical checkout.

`package.json` lists the probes that still have a runnable active-profile wire
dependency. E136 records the normal, capture, and probe identities.
